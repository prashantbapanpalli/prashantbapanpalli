### How I work

- **Problem first.** I start from a real bottleneck in public services, then pick the simplest method that solves it.
- **Measured, not claimed.** Held-out test sets, time-based splits, honest baselines, and I report the numbers from before and after I fixed bugs.
- **AI-assisted engineering.** I build with AI coding tools such as Claude Code and spend my own effort on design, evaluation and understanding why things work.
